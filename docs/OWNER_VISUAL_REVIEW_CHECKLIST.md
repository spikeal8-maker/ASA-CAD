# Owner visual review checklist

When reviewing an ASA-CAD screen against a KOMPAS reference, check in this order:

1. overall information hierarchy;
2. command/workspace grouping and order;
3. top chrome height versus work area;
4. tree width/row density;
5. ParameterPanel width/field rhythm;
6. command active/disabled/selected states;
7. viewport selection/preselection/preview clarity;
8. text readability;
9. icon meaning/consistency;
10. save/rebuild/error visibility;
11. compact/overflow behavior at 1366x768;
12. 2K/4K scaling and panel caps;
13. phone/tablet re-composition;
14. keyboard/touch discoverability;
15. deliberate differences from KOMPAS.

A screenshot that looks acceptable at one resolution is not sufficient. Final acceptance requires the viewport matrix and interaction tests.
