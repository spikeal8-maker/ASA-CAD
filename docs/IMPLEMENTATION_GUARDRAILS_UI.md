# UI implementation guardrails

- Do not use raw physical screen resolution as the primary layout breakpoint.
- Do not solve narrow screens by reducing all font/icon sizes.
- Do not stretch panels/command groups indefinitely on 2K/4K/ultrawide.
- Do not apply whole-app CSS transforms that desynchronize 3D/2D pointer coordinates.
- Do not hide a working desktop command on phone without a defined alternate discovery path.
- Do not introduce hover-only essential behavior.
- Do not add a permanent command before its stable ASA command ID/parameters/fixture exist.
- Do not copy KOMPAS icon artwork.
- Do not declare visual parity from one Full-HD screenshot.
- Do not accept M2 until required viewport/DPI/zoom/mobile cases pass.
