# ASA-CAD UI specification index

Read these together for product UI work:

1. `UI_COMMAND_SPEC.md` — commands/buttons/groups/parameter panels.
2. `WORKSPACE_INTERACTION_SPEC.md` — model/drawing work area and selection/navigation.
3. `SHORTCUTS_SPEC.md` — keyboard and remapping.
4. `MOBILE_RESPONSIVE_SPEC.md` — phone/tablet/touch.
5. `DISPLAY_LAYOUT_SPEC.md` — HD/FHD/2K/4K/ultrawide, DPI, zoom, typography and layout geometry.
6. `VISUAL_REFERENCE_SPEC.md` — KOMPAS reference mapping and visual acceptance.
7. `M2_VISUAL_ACCEPTANCE.md` — acceptance gate.
8. `TZ_CRITICAL_AUDIT.md` — known gaps and audit verdict.
