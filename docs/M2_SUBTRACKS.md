# M2 UI subtracks

M2 permanent UI work is split into coordinated subtracks so layout does not become an afterthought.

- **M2 core shell** — command/application shell from registry.
- **M2A visual fixtures** — deterministic owner-review states and screenshot regression.
- **M2I interaction** — mouse, keyboard, touch, workspace interaction, mobile shell.
- **M2R display/resolution** — HD/FHD/2K/4K/ultrawide, DPI, zoom, UI Scale, height stress.
- **M2V visual parity** — approved KOMPAS reference mapping, measurements and deliberate differences.

M2 cannot receive final visual acceptance until all applicable M2A/M2I/M2R/M2V gates pass.
