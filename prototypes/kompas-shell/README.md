# Прототип оболочки Детали по эталону КОМПАС-3D

Самостоятельная HTML-страница, которая показывает, как может выглядеть и вести себя оболочка Детали ASA-CAD, если довести её до вида КОМПАС-3D. Это эталон для визуальной сверки и переноса в `src/web`, а не часть продукта: сборка, `CadApplication`, реестры и тесты не затронуты.

Открыть: `prototypes/kompas-shell/index.html` в браузере. Сборка не нужна, нужен интернет для Three.js r128 с cdnjs. Рассчитано на окно шириной от 1400 CSS px (масштаб 100 %, как у эталона 1920×1080).

## Из чего собрано

Ячейки команд 120×25 и 26×25. Панель быстрого доступа — 16 кнопок шириной 26/47, прижата к левому краю графической области (x = 356). Вкладки рейки: Дерево, Параметры, Переменные, Библиотеки. |

Иконки нарисованы заново в стиле `CadIcon`. Логотипы и иконки КОМПАСа не использованы.

## Что работает

- Переключение наборов инструментов; горизонтальная прокрутка панелей колесом.
- Дерево: раскрытие узлов, выбор, видимость («глаз»), поиск, маркер конца дерева.
- «Элемент выдавливания» по выбранному эскизу: панель параметров с разметкой КОМПАСа (Результат, Сечение, Направляющий объект, Способ, Расстояние, Угол, Симметрично, Второе направление, сворачиваемые секции, строка сообщения), фантом в 3D, подтверждение и отмена (Enter / Esc, кнопки на панели и в панели быстрого доступа), узел операции в дереве.
- «Создать эскиз»: по выбранной плоскости или через указание плоскости; режим эскиза меняет меню, выделяет вкладку зелёной линией, ставит вид по нормали и показывает кнопку выхода.
- 3D-вид: параллельная проекция, Z вверх, изометрия как в КОМПАСе, вращение, сдвиг, масштаб к курсору, стандартные виды, «Показать всё», полутоновое/каркасное отображение, триада осей, подсветка и выбор плоскостей, эскиза и тела.
- Отмена/повтор, поиск по командам (Alt+/), меню «Файл», светлая и тёмная тема.
- «Статус в ASA-CAD» — отметки на каждой кнопке по реестру: реализовано, запланировано, отложено, нет в реестре; сводка по текущему набору.

Остальные команды ничего не строят и показывают подсказку со статусом команды в ASA-CAD.

## Известные расхождения с эталоном

- Наполнение панелей соответствует v23; в v25 состав может отличаться. Для точной сверки нужен захват v25 с подписями кнопок.
- Размеры панели параметров и строки состояния в `layout.json` v25 не определены (`unresolvedMajorZones`), они сняты с v23.
- Только масштаб интерфейса 100 %; вариантов UI Scale нет.
- На узком экране панель управления открывается поверх графической области, инструментальная область прокручивается.

## Как переносить в продукт

- Цветовые токены и размеры — блок `:root` в начале `<style>`; тёмная тема основная, светлая переопределяет те же токены.
- Структура `TOOLSETS` в скрипте повторяет группы `layout-registry.v2.json` и ссылается на id из реестра команд — её можно заменить чтением реестров.
- Разметка использует те же зоны, что `CadShellTop`/`CadShellCommandGroups`/`DocumentTree`/`ExtrudeParameterPanel`, поэтому перенос можно делать по одной зоне за PR.
