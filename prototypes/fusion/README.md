# ASA-CAD / Fusion — визуальная оболочка

Статус: **REFERENCE_ONLY / не подключено к продукту**. Эта ветка сохраняет русскоязычный Fusion-like UI v3 как референс. В ней нет второго CAD-ядра, независимых документов, командного реестра или базы.

## Состав

- index.html — автономный HTML/CSS/JS-прототип. Работает без сети, показывает ленту, дерево, панель проектов, меню, параметры, 2D-сетку, видовой куб. Открывается двойным нажатием в браузере.
- skin-selection.contract.json — целевой контракт выбора оболочки на старте, ещё НЕ интегрирован в приложение.
- icon-inventory.v1.json — фактическая карта команд и встроенных в v3 SVG. Паритет по пиктограммам НЕ принят.
- tests/reference-smoke.mjs — локальный Node.js smoke-test структуры прототипа и контракта.

Команда проверки из корня репозитория: node prototypes/fusion/tests/reference-smoke.mjs. Страница не является продуктовым маршрутом /cad/ и не должна имитировать действующие CAD-операции.

## Конечная схема: одно ядро, три оболочки

Пользователь должен выбирать при запуске: **Fusion** (новая оболочка), **Компас** (существующий src/web/kompas), **Vassalite** (по описанию владельца, Tinkercad-подобная оболочка). В текущем main нет именованного Vassalite-модуля: нужно выяснить, является ли им LegacyCadShell или другая ветка, до подключения выбора. Не подменять отсутствующий skin фиктивным экраном.

Первый запуск: экран выбора. Последующие: восстановление предпочтения интерфейса, при этом меню «Интерфейс» позволяет его сменить. Оболочка — настройка UI, НЕ часть CadDocument. Смена оболочки не сбрасывает документ, undo/redo, выделение, камеру, параметры и историю.

Поток данных для всех оболочек:

    Fusion / Компас / Vassalite (UI)
                   ↓
    единые CadUiAction и command registry
                   ↓
    CadApplication + CadDocument + persistence
                   ↓
    CadViewport, PlaneGCS, OpenCascade

Запрещены отдельный WebGL/CAD-runtime, второй renderer, независимые command handlers, параллельные модели данных/состояния и сохранение mesh в документ. HTML-макет нельзя переносить в App.tsx с его демонстрационным состоянием.

## Этапы Fusion (пока другие оболочки НЕ дорабатываем)

### F0. Сохранить v3 как самостоятельный reference (этот PR)
- Точная копия HTML, SHA256, явные рабочие ограничения.
- Перечень значков, групп ленты, инструментов и проверка структуры.
- Только каталог prototypes/fusion; ядро, Компас, persistence и main не трогать.

### F1. Значки — предметная визуальная сверка
- Для каждого инструмента отдельно: референс → самостоятельно созданный SVG → размеры и визуальное отклонение.
- Размеры 16/24/32/40 px; геометрия, объём, заливка, тень, подсветка, стрелка, отступ и состояния normal/hover/pressed/disabled.
- Текущее v3 повторно использует часть общих значков для разных команд. Это незавершённость, не 100% паритет.
- Не брать сторонние фирменные SVG Autodesk из установленной программы; рисовать собственные по эталонным изображениям.
- Результат: полный каталог иконок и side-by-side PNG каждого семейства со статусами PASS / GAP.

### F2. Меню и выезжающие панели
- Точный порядок групп, размеры кнопок и подписей, split-button, popup anchor, вложенные меню, tooltip, disabled и keyboard focus.
- Escape / клик вне / повторный вызов закрывают панели; position/flip в пределах окна.
- Панель параметров открывается при команде и сохраняет state одного CadApplication.
- Отдельный evidence сценарий: раскрыть СОЗДАТЬ → выбрать Выдавливание → параметры → подтверждение/отмена → undo.

### F3. Рабочее поле
- Сетка и оси изометрии, ViewCube, камера, навигация, floating Browser, дерево, timeline, нижняя панель.
- Сценарии 1: пустая Деталь; 2: открыта панель файлов, поле сдвинуто; 3: открыты параметры команды.
- Орбита, панорамирование, масштаб, виды и выбор XY/XZ/YZ в продукте используют существующий CadViewport/контроллер камеры, не новый canvas-движок.

### F4. Встраивание и выбор трёх оболочек после разрешения gate
- Сейчас spec/process/active-work.v1.json указывает FULL_REPOSITORY_HEALTH_AUDIT, productCodeStartAllowed=false.
- Продуктовый PR разрешён только после GREEN или принятого владельцем YELLOW по аудиту.
- Интеграция: отдельные компоненты FusionTop / FusionRibbon / FusionTree / FusionParameters / FusionViewportChrome с props от действующего App; shared action bindings без дублирования.
- Затем selector 3 skin на первом запуске, сохранение пользовательского предпочтения вне CAD-документа; реальные пути для Компаса и Vassalite.
- Проверить protected Part, создание и сохранение эскиза, undo/redo, открытие файлов, переключение shell без потери состояния; exact-HEAD CI и независимый review; в main только после решения владельца.

## Критерии приёмки

Эталон пустого состояния: 2048×1137, DPR1, zoom100%; также 1600×900, 1366×768, 1024×768.
Проверить top/toolbar, layout каждой группы, SVG icon per action, всплывающие меню, окно параметров, дерево, 3D поле, view cube, navigator, timeline. Для границ крупных зон целевой допуск ±2 CSS px и ноль обрезанных слов/перекрытий/неработающих кнопок.

100% по иконкам можно заявить только после индивидуальной проверки каждой команды во всех состояниях. Сейчас: ICON_PARITY=NOT_VERIFIED; POPUP_PARITY=PARTIAL; VIEWPORT_PARITY=DEMO_2D; CORE_INTEGRATION=NONE.

## Границы и открытые вопросы

- Включённые в текущую HTML-демонстрацию картинки карточек проектов происходят из предоставленных владельцем скриншотов. До продакшна заменить на самостоятельные тестовые превью; не включать скриншоты оригинального Fusion в исходники.
- Не импортировать vendor SVG/логотипы Autodesk и не использовать бренд в интерфейсе.
- Не менять CadDocument/schema/OpenCascade/PlaneGCS/solver, src/web/App.tsx и действующие оболочки в этом PR.
- Не выполнять merge, релиз, deployment и не объявлять UI finished/parity verified без отдельного согласования.

## F1/F2 — продолжение 2026-11-05: Fusion visual v4

Новый вход: **fusion-v4.html** в том же каталоге. Это независимый локальный просмотр без сервера и интернета. Для корректной загрузки нужны соседние файлы **icon-atlas.v4.js**, **ui-controls.v4.js**, **ui-v4.css**, **icon-review.v4.js** и **icon-review.v4.css**. Прежний index.html остаётся неизменённым проверяемым эталоном v3.

Новые изменения:
- 51 оригинальный SVG-рисунок привязан к **51 различной по смыслу команде** на семи вкладках (68 размещений). Никакая команда больше не получает общий SVG по ошибочному старому ключу; одинаковые по смыслу команды между вкладками сохраняют один рисунок.
- Каждая видимая кнопка имеет отдельную подпись, aria-label, состояние disabled и подсветку hover/pressed/focus; верхняя системная полоса отсутствует.
- Выпадающие меню привязаны к своим группам. Реализованы hover-preview с названием, большим значком и описанием команды, клавиатурные стрелки, Home/End, Escape, закрытие снаружи.
- Окно ввода параметров «Выдавливание» и исходные элементы панели проектов, сетки и ViewCube работают на уровне демонстрации; **это не работа ядра**.
- Экран инвентаризации: **fusion-v4.html?icons=1** — 51 рисунок на одном листе с названиями и отметками «Сверить с эталоном».
- icon-inventory.v4.json содержит индивидуальные статусы будущей приёмки. Все они DRAWN_AWAITING_VISUAL_APPROVAL: внешнее сходство **не** признано 100%.

Выполненные проверки: node prototypes/fusion/tests/reference-smoke.mjs (v3 original PASS), отдельный Puppeteer-browser smoke 2048×1137 и 1366×768 (PASS), 7 вкладок/68 кнопок/51 разных SVG, меню/preview, окно параметров, экран сверки, ноль JS pageerror и внешних HTTP-запросов. PNG в evidence/, в том числе fusion-v4-empty.png, fusion-v4-menu.png и fusion-v4-icons-review.png.

Для повторения браузерного теста требуется установленный Puppeteer и Chromium/Chrome. Используется стандартный резолв пакета puppeteer или путь из переменной окружения ASA_CAD_PUPPETEER_MODULE, путь к Chrome — ASA_CAD_BROWSER_EXECUTABLE. Не включать постоянные пути с D2-R2 в тесты. Команда запуска: node prototypes/fusion/tests/v4-browser.mjs.

Незакрытая работа: точная покомандная сверка с эталонной версией установленного Fusion, дальнейшая проработка tooltip, nested popup и особенностей ViewCube, исправление несоответствий в SVG по скриншотам. Требование владельца 100% остаётся **целевым**, не достигнутым. Встраивание в приложение и экран выбора трёх оболочек остаются заблокированы текущим audit gate и не осуществлены.

## F1/F2 — v5: проверка настоящего Fusion и русская оболочка по его данным

Актуальный вход — **fusion-v5.html**. Открывать вместе с соседними native-*.v5.js, native-ui.v5.css и icon-atlas.v4.js. v3/v4 сохранены как предыдущие состояния, не как источник полного состава Fusion.

На D2-R2 действительно запущен read-only экспортёр внутри Fusion 2706.1.17. Ошибок экспорта нет. Добавлено чтение **promotedControls**, поскольку порядок закреплённых кнопок отличается от порядка пунктов выпадающего меню. В зарегистрированных UI-каталогах найдено 1384 уникальных command ID; это НЕ число вручную проверенных функций. В видимом рабочем пространстве «Проектирование» — 7 вкладок, 28 уникальных панелей, 180 разных команд и 142 размещения закреплённых кнопок. Эти метаданные хранятся в native-reference.v5.json; все пользовательские названия переведены в native-labels.ru.v5.js.

**Фактическая интерактивная проверка оригинала:** наведение на 78 различных команд; нажатие на 77 из них, включая 3 недоступные кнопки, где проверено отсутствие действия. На «Создать форму» только наведение: переключение с изменением документа не выполнялось. Открыты семь основных меню Solid и вложенные списки «Массив»/«Создать плату». Сняты короткие/развёрнутые подсказки, окна и отмена команд. Подробно проверено «Выдавливание»: четыре списка параметров, тонкостенный тип, сворачивание, разворачивание, перемещение панели и возврат позиции. Это НЕ исчерпывающий обход всех команд и их состояний.

Исправлены реальные ошибки предыдущих версий: значок «ножниц» означает «Автоматическое моделирование», а не «Обрезать»; на ленте находится «Разделить тело», а не «Фаска»; в группе вставки три закреплённые команды; меню «Создать» содержит 26 пунктов, а не 7. В v5 меню строятся из native ID с исходным порядком, разделителями, подменю и disabled-состояниями. Подсказки переработаны в тёмные по фактическому поведению оригинала; иллюстрации — собственные, не ресурсы Autodesk.

Перенесены **начальные состояния 10 разных окон**: Выдавливание, Вращение, Отверстие, Прямоугольный массив, Скругление, Оболочка, Объединить, Разделить тело, Переместить/Копировать, Автоматическое моделирование. У «Выдавливания» воспроизведены проверенные варианты начала/направления/протяжённости/операции и переключение тонкостенного режима. Работают перетаскивание, сворачивание, повторное открытие, выбор значений и отмена. Непроверенные списки НЕ наполняются вымышленными значениями. Для ещё не перенесённой команды показан явный статус незавершённости, а не прежняя фиктивная форма «Объект / Значение 10 мм».

**Геометрия не выполняется:** OK недоступна в пустом состоянии и без подключения ядра; события asa-cad:native-ui-request и asa-cad:native-selection-request содержат nativeCommandId и referenceOnly=true. Ни один UI-проход не считается проверкой математической операции.

Среда оригинала измерена: **110 DPI**, физическая клиентская область 2073×1117. Размеры переводятся в DIP коэффициентом 96/110 по отдельным элементам, без глобального масштабирования страницы/canvas. Контрольные снимки v5 сняты также при CSS 1809×975 и DPR 110/96. Русские длинные подписи и различия рендеринга требуют отдельной визуальной приёмки — совпадение пикселей не заявлено.

Проверка: **node prototypes/fusion/tests/v5-native-browser.mjs** (Puppeteer, те же переменные окружения, что у v4). Проверяются все 7 лент, 180 переводов, исходные количества меню, вложенный массив, hover, 10 окон, списки Выдавливания, отсутствие работающего OK без геометрии, перетаскивание/сворачивание/отмена, размеры 2048/1600/1366/1024, отсутствие внешних HTTP-запросов и JS-ошибок. Результат — evidence/fusion-v5-browser-checks.json.

**Доказательства:** reference_capture/observed-cases.v1.json — поэлементный перечень 78 исследованных команд с именами и SHA256 приватных снимков/UIA. Оригинальные снимки и полный экспорт остаются только в Documents/ASA-CAD-Fusion-Captures на D2-R2; в Git нет изображений или ресурсов Autodesk. Публичные PNG в evidence/fusion-v5-* — наша страница.

Оставшиеся разрывы: остальные команды, контекст эскиза/непустой модели, полные наборы состояний каждого окна, все оригиналоподобные значки, поведение графического поля и подключение единого ядра. Некоторые SVG пока семейные/приблизительные или явно missing-reference; статусы задаёт asaNativeIcon.status(id). Служебная правая кнопка закрепления окна ещё не принята и не имитирует подтверждённую работу. Полное функциональное и визуальное соответствие **не достигнуто**. Выбор трёх оболочек и продуктовый audit gate не изменены.

### Продолжение обхода: построения и анализ

Проверены дополнительно 19 команд построений и 10 команд анализа: короткое/длительное наведение, открытие и Escape/отмена. Вместе с прежним смещением плоскости теперь открыта вся группа «Построить»: 20 пунктов, включая ПСК. У 10 команд анализа сняты начальные окна; их поля пока не перенесены в нашу страницу.

**Новая общая русская панель:** native-construction.v5.js реализует 19 методов вспомогательной геометрии и ПСК поверх одного контроллера native-dialogs.v5.js. Списки «Тип / Метод» проверены кликами в оригинале: 8 методов плоскостей, 5 осей, 6 точек. Смена метода действительно заменяет поля выбора, а не открывает одинаковый макет. Подтверждены исходные наборы выбора граней/рёбер/плоскостей/точек, цепочка, варианты U/V для перпендикулярной плоскости и переключение протяжённости смещения. После выбора «До объекта» в пустом состоянии не добавляются вымышленные поля. Escape в оригинале закрывает всю команду даже из списка метода; наш контроллер ведёт себя так же.

Общее число перенесённых начальных состояний — **30** (10 основных + 19 построений + ПСК). Это не 30 полноценных математических операций. Новые независимые значки построений имеют статус redrawn-unaccepted до покомандной визуальной приёмки.

Регрессия **node prototypes/fusion/tests/v5-construction-browser.mjs** проверяет все 19 методов, реальные количества вариантов, переключения типа/метода и состава полей, checkbox, сворачивание, перенос, resize, отмену, недоступное ОК без ядра, размеры 1600/1366/1024/768. Итог — evidence/fusion-v5-construction-checks.json; собственные PNG — fusion-v5-construction-methods.png и fusion-v5-construction-floating.png.

Контроль исследования: 78 отдельных команд с hover, 77 нажатий (3 недоступных), 74 открытых состояния. Непроверенные режимы/параметры не помечены готовыми. Полного обхода всего Fusion и полноценного CAD-подключения в этой поставке нет. Исходные снимки и полный API-export по-прежнему остаются приватно на D2-R2.
