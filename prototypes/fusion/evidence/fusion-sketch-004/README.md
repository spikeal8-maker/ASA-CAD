# FUSION-SKETCH-004 — сравнительная приёмка

Эталон: установленный Autodesk Fusion 2706.1.17 на D2-R2 в активной среде Sketch. Сравниваемая реализация: ASA-CAD Fusion, исходный SHA `b9bab762929677eb6ff4fbf3a4f1b2c933a72085`.

- [Сравнение 1920×1080](native-vs-asa-1920x1080.png) — слева оригинальный Fusion, справа ASA-CAD Fusion.
- [Сравнение 1366×768](native-vs-asa-1366x768.png) — слева оригинальный Fusion, справа ASA-CAD Fusion. Нативное окно Fusion имело фактическую минимальную ширину 1393 px и уменьшено до 1366 px в сравнительной иллюстрации.
- Каждый снимок сделан непосредственно на D2-R2. Интерфейсы представлены для анализа, не как доказательство пиксельного соответствия. Геометрия тестового отрезка и содержимое дерева в двух программах различаются.

## Проверено реальными действиями

- Выбор XY/XZ/YZ → создание нового эскиза и немедленная активация, Sketch Ribbon/Palette, выделение в дереве, завершение, повторное открытие и сохранение.
- Линия, прямоугольник двумя щелчками (четыре линии), окружность, дуга «центр — начало — конец»: 7 реальных CAD-сущностей.
- Линейный driving-размер 40 мм и ограничение «Горизонтальность» через интерфейс Fusion; Undo → Redo; сохранение и повторное открытие.
- Размеры 1920×1080 и 1366×768: координаты левой панели и палитры проверены с допуском 6 CSS px.
- Локальные проверки PASS; воспроизводимые браузерные проверки находятся в `tests/launcher/fusion-sketch-004.mjs` и `tests/launcher/fusion-sketch-004-tools.mjs`.

## Не приняты как полное соответствие Fusion

- Дерево ASA-CAD не повторяет полностью иерархию Document Settings / Named Views / Origin / Sketches и состояния строк оригинала.
- Проекции геометрии, 3D Sketch, орбитальное вращение в Sketch и часть операций Modify не реализованы либо остаются недоступными.
- Кнопки неподдержанных native-команд остаются отключёнными. Наличие иконки/меню само по себе не означает выполнение команды.
- SVG-иконки, русский перевод, контекстные меню, точность прокрутки и размеры всех блоков не прошли полную покомпонентную визуальную приёмку.
- Для sketches на гранях не получено независимого браузерного подтверждения точного поведения камеры и всех StableRef-сценариев.

**Статус:** исправлено создание и активация Sketch; полная визуальная и функциональная эквивалентность Autodesk Fusion пока НЕ ПРИНЯТА.
